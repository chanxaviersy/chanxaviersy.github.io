# Xavier Chen — Personal Portfolio Website

> 🌐 Live site: **https://chanxaviersy.github.io**

个人作品集网站，展示我的项目、技能与背景。

## 技术栈

- **HTML5** + **CSS3**（纯静态）
- **Google Fonts** — Inter + JetBrains Mono + Noto Sans SC
- **原生 JavaScript** — Typing 效果、动画、滚动监听
- **GitHub Pages** — 自动部署

## 特性

- 🎨 暗色主题 + 渐变色彩系统
- ✨ Typing 效果、滚动动画、3D 卡片倾斜
- 📱 完全响应式（移动端 / 平板 / 桌面）
- ⚡ 零依赖、纯静态、加载快
- 🔍 SEO 优化（Open Graph、Twitter Card、meta 标签）

## 目录

```
00-personal-site/
├── 📄 index.html         # 主页
├── 🎨 style.css          # 样式
└── 📄 README.md          # 本文件
```

## 本地预览

```bash
# 方式 1：直接打开
open index.html

# 方式 2：用 Python 启服务
python3 -m http.server 8000
# 访问 http://localhost:8000
```
